Installation & Pairing Guide

Get up and running with Antigravity Mobile IDE in less than five minutes. All code runs locally on your PC and your phone.

Supported Environments: Windows 10/11 (64-bit), Node.js 18+ (tested on Node 20 & 24), and Android 10+ (API 29+).

Step 1: Install Desktop Bridge

Clone the repository and install dependencies on your Windows host workstation:

# Clone repository
git clone https://github.com/deekshudevang/Antigravity-Mobile-IDE.git
cd Antigravity-Mobile-IDE

# Install dependencies and verify test suite
npm install
npm test

Step 2: Start Bridge & Retrieve Admin Token

Launch the server from PowerShell or Command Prompt:

node src/http-server.mjs

At startup, the bridge displays your unique, cryptographically random admin token:

============================================================
🔑 [ADMIN SECURITY] Local Admin Token:
   dc38c62258294e742eedce77dd0f3c2b5f2faa5e7ad4809bef9d152552078ab5
   Required for /admin, /setup, and /api/admin/* endpoints.
============================================================

Copy this token and open http://localhost:5000/setup in your browser to paste it into the setup wizard.

Step 3: Sideload the Android Companion APK

  1. Download the pre-compiled app-debug.apk from the latest GitHub Release (or build locally using cd android && ./gradlew assembleDebug).
  2. Transfer the APK to your phone and install it (allow installation from unknown sources in Android settings).
  3. Open the Antigravity Mobile app.

Step 4: Connect & Pair over Tailscale

  1. Find your PC's numerical Tailscale IPv4 address by running tailscale ip -4 on Windows (e.g. 100.85.12.34).
  2. In the Android app, go to Settings → Connection.
  3. Enter your PC's Tailscale IP (e.g. 100.85.12.34) and Port 5000.
  4. Click Test Connection. The indicator will turn green once the bridge is reached.
  5. Retrieve the 5-minute pairing code from your PC setup wizard (or run node scripts/generate-tokens.mjs) and enter it under Remote Control Pairing.

Your phone is now securely paired! You can monitor chats, review approvals, browse files, and control your workstation from anywhere on your Tailnet.
