Release Changelog

Documented version history adhering to Keep a Changelog and Semantic Versioning.

Version 2.0.0 (2026-11-17)

Security Hardening & Capability RBAC

  • SEC-06 Admin Token Defense: 32-byte cryptographically secure startup token validated with crypto.timingSafeEqual. Rejects reverse proxy headers (e.g. X-Forwarded-For) on administrative routes.
  • Supervisor Path Traversal Protection: Enforced canonical realpath boundary validation on /api/supervisor/file/read and /list.
  • Scoped Capability RBAC: Added granular permissions across 29 target API routes with GIT_READ and GIT_WRITE separation.
  • Helper Protocol Security: Replaced unauthenticated loopback helper socket with environment-isolated 32-byte handshake, 64KB frame limits, and monotonic sequence checking.
  • CI Automation: Added GitHub Actions CI pipeline running Node suites, WCAG contrast checks, and Android unit tests.

Version 1.0.0 (2026-11-04)

Antigravity 2.x Architecture Support

  • Relocated chat turn extraction to inspect isolated iframe webview targets (extensionView=true).
  • Full support for Antigravity 2.x questionnaire cards (ask_question, ask_permission).
  • Smart quick response action buttons ('Yes', 'No', 'Continue', 'Stop').
  • Jetpack Compose Android companion app with dynamic wallpaper theming (Material You).
