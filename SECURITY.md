## Reporting a Vulnerability

We take the security of **Antigravity Mobile IDE** seriously. If you believe you have discovered a vulnerability that affects remote access, token authentication, path traversal, or command execution, please report it responsibly.

### How to Report Privately

1. **GitHub Private Vulnerability Reporting (Preferred)**:
   - Navigate to the [Security Advisories](https://github.com/deekshudevang/Antigravity-Mobile-IDE/security/advisories) tab of this repository.
   - Click **"Report a vulnerability"** to submit your findings privately to the project maintainers.
   - If private vulnerability reporting is not yet enabled by the repository owner, please open a minimal issue titled `[Security] Requesting maintainer contact for private report` without disclosing details, or contact the maintainer directly through their GitHub profile.

> **Important**: Please do **not** disclose security vulnerabilities publicly in issues or discussions until maintainers have had an opportunity to review and address them.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please include:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal proof-of-concept.
- The environment details (OS version, Node.js version, Android version).
- Any proposed remediation or patch.

We will acknowledge receipt of your report within 48 hours and provide regular updates on triage and patching.
