Troubleshooting & FAQ

Quick solutions to common network, pairing, and runtime errors.

Connection & Tailscale Diagnostics

Symptom: Unable to resolve host: No address associated with hostname

Cause: Android cannot resolve Tailscale MagicDNS names (e.g. msi.tail3cd1f6.ts.net) unless Tailscale VPN is active on the phone and MagicDNS is supported by local DNS.

Solution:

  1. Use your PC's numerical Tailscale IPv4 address (e.g. 100.85.12.34) in the Android app. Find it by running tailscale ip -4 on Windows.
  2. Ensure the Tailscale VPN switch is toggled ON in the mobile Tailscale application.

Symptom: Unable to resolve host "https"

Cause: The prefix https:// was entered into the "Tailscale IP" field, creating a malformed URL (https://https://...).

Solution: Enter strictly the IP address or hostname (e.g. 100.85.12.34), without http:// or https://.

Symptom: Admin endpoints return HTTP 401 or 403

Cause: SEC-06 local admin protection requires an explicit 32-byte secret token.

Solution: Look at your Windows terminal where the server started. Copy the 64-hex token under 🔑 [ADMIN SECURITY] and paste it when prompted by the web setup wizard.

Frequently Asked Questions

Does this send any code to Google or third-party servers?

No. The bridge binds to local loopback (127.0.0.1:5000). When using Tailscale, all communication is strictly peer-to-peer over an encrypted WireGuard mesh directly between your phone and PC.

Do I need Microsoft Visual Studio to use the mobile app?

No. Screen mirroring and keyboard input use Chrome DevTools Protocol (CDP) screencast streaming, which runs out of the box with zero native C++ compiler dependencies.

Can I approve commands and tool actions from my phone?

Yes. The Android app displays interactive questionnaire and approval cards (`ask_question`, `ask_permission`), letting you click `Run`, `Allow`, or `Reject` directly from your mobile screen.
