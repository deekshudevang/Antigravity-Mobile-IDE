Security, Privacy & Threat Model

Antigravity Mobile IDE was designed with a defense-in-depth posture. Controlling a developer machine remotely requires strict access control, rigorous boundary isolation, and zero ambient trust.

Core Security Guarantees

Loopback Isolation & SEC-06

The bridge binds strictly to 127.0.0.1:5000. Administrative endpoints require a 32-byte cryptographically secure startup token validated with constant-time equality. Reverse proxy headers (e.g. X-Forwarded-For) are rejected to eliminate IP-spoofing bypasses.

Hardware Keystore Storage

On Android, access and refresh tokens are encrypted using AES-256-GCM hardware keys inside Android Keystore. Backups are disabled (allowBackup="false"), preventing credential exfiltration via cloud backups.

Rotating Anti-Theft Tokens

Dual JWT credentials utilize short 15-minute access tokens and rotating refresh tokens. Replaying an expired or already-used refresh token triggers anti-theft detection, terminating the device's token family and severing active sockets.

Realpath File Traversal Defense

Workspace file browsing canonicalizes all paths with fs.realpathSync. Directory traversal (../, %2e%2e%2f), Windows junctions, and sensitive files (.env, .git, keys) are denied with generic 403 Forbidden responses.

Reporting Vulnerabilities

We welcome security audits and researcher reports. Please report potential vulnerabilities privately through GitHub Private Vulnerability Reporting.
