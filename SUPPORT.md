# Getting Support for Antigravity Mobile IDE

Welcome to the **Antigravity Mobile IDE** support guide. We are an open-source community project maintained by volunteers.

---

## 1. Documentation & Self-Help

Before opening an issue, check the following resources:
- **[Installation Guide](https://deekshudevang.github.io/Antigravity-Mobile-IDE/install/)**: Step-by-step setup for Android and Windows.
- **[Troubleshooting & FAQ](https://deekshudevang.github.io/Antigravity-Mobile-IDE/troubleshooting/)**: Solutions to common Tailscale DNS, pairing, and CDP connection problems.
- **[Known Limitations](docs/KNOWN_LIMITATIONS.md)**: Hardware boundaries, toolchain requirements, and platform limits.

---

## 2. Where to Ask Questions

- **Feature Ideas & General Questions**: Use [GitHub Discussions](https://github.com/deekshudevang/Antigravity-Mobile-IDE/discussions).
- **Bug Reports**: If you found a confirmed defect with reproducible steps, open a [Bug Report](https://github.com/deekshudevang/Antigravity-Mobile-IDE/issues/new?template=bug_report.yml).
- **Security Vulnerabilities**: Do **not** post security bugs in public issues. Follow [SECURITY.md](SECURITY.md) to report privately.
